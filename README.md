# 🎓 Student Record System

A simple web-based **Student Record Management System** built using **PHP and MySQL**.  
This project allows users to securely manage student records with full CRUD functionality and authentication.

---

## 🚀 Features

- 🔐 User Registration and Login System
- 📋 View Student Records (Read)
- ➕ Add New Students (Create)
- ✏️ Edit Student Information (Update)
- ❌ Delete Student Records (Delete)
- 🛡️ Secure queries using PDO Prepared Statements
- 🔄 Session-based authentication

---

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML & CSS
- Apache (Laragon)

---

## 📂 Project Files

- `index.php` – Entry point (redirects user)
- `login.php` – Login page
- `register.php` – User registration
- `authenticate.php` – Login processing
- `dashboard.php` – Main system interface
- `add_student.php` – Add student
- `edit_student.php` – Update student
- `delete_student.php` – Delete student
- `logout.php` – Logout system
- `config.php` – Database connection
